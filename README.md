## 🎨 Suite Contents

- 🖥️ **Hyprland (`~/.config/hypr/`)**: Dynamic tiling layouts, window rules, keybindings, animations.
- 🐚 **Omarchy Shell (`~/.config/omarchy/`)**: Custom bar layout, clock, weather, battery indicators.
- 🎵 **Spotify Glass Flow Widget**: Native audio controller & multi-tab switcher.
- 🎨 **Rick & Morty HD Themes & Wallpapers**: 1080p cosmic themes & auto-rotator.
- 📟 **Terminals**: Foot, Kitty, Alacritty, Ghostty with custom ANSI palettes.
- ⭐ **Starship Prompt**: High-speed asynchronous shell prompt.

## 🚀 1-Command Installation & Restore

```bash
# Clone repository
git clone https://github.com/OLAg-shs/omarchy-dotfiles.git
cd omarchy-dotfiles

# Restore entire desktop configuration
./install.sh
```

---

## 🔄 1-Click Backup

```bash
# Backup current changes and auto-push to GitHub
cd ~/Projects/omarchy-dotfiles
./backup.sh
```
